# Kochi University Regulations

Extract Kochi University academic regulations as JSON.

## Installation

```sh
git clone https://github.com/P4suta/kochi-u-rulesets.git
cd kochi-u-rulesets
cargo install --path crates/cli
```

## Usage

```sh
kochi-university-regulations build --strict
```
